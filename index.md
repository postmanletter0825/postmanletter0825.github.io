# gogcli (personal)

This site is the homepage of "gogcli", a personal OAuth client used only by its owner (GitHub: postmanletter0825).

It lets the owner access their own Google account data (Gmail, Calendar, Drive, Docs, Sheets and other Google Workspace services) from the command line using gog, an open-source CLI (github.com/openclaw/gogcli).

This app is not offered to or intended for any other users.
