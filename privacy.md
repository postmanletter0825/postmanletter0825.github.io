# Privacy Policy

Last updated: 2026-09-23

This policy applies to "gogcli", a personal OAuth client used only by its owner (GitHub: postmanletter0825) to run gog, an open-source command-line tool (github.com/openclaw/gogcli), against the owner's own Google account.

## Data accessed

With the owner's consent, the app may access Google user data through Google APIs, including Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Contacts, Tasks, Meet, Chat, Classroom, Apps Script, Analytics, Search Console, Google Ads, YouTube and Photos.

## How data is used

Google user data is used only to display or act on the owner's own data at the owner's request on the owner's local computer. The data is not sold, not used for advertising, and not used to train AI or machine learning models.

## Storage and sharing

Data retrieved from Google APIs is processed locally and is not sent to, stored on, or shared with any server or third party operated by the developer. OAuth tokens are stored in the operating system keychain on the owner's computer.

## Revoking access

Access can be revoked at any time from https://myaccount.google.com/permissions

## Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
